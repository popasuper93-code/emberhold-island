# EMBERHOLD: Остров Пепла

Оригинальная мобильная 3D survival-игра от первого лица (Three.js r128).

Механики вдохновлены Rust + мобильными клонами (Oxide, Last Island), но всё оригинальное: названия, предметы, арт, звуки.

## Играть

- **Браузер**: открой `www/index.html` в Chrome / Edge (лучше телефон или DevTools → Landscape).
- **Android APK**: Actions → Build APK → Run workflow → скачай артефакт.

## Что реализовано в этом прототипе

### Этап 1 — Лобби
- 3D-сцена (закат, форт, дым, персонаж)
- Рулетка скинов, инвентарь скинов
- Полный гироскоп + калибровка (iOS permission, 90°/270°)
- Настройки, localStorage

### Этап 2 — Мир + Выживание
- Процедурный остров по seed
- День/ночь, биомы (упрощённо)
- Статы: HP, голод, жажда, температура, радиация, кровотечение
- Добыча деревьев и руды (хотспот)
- Инвентарь 24 + хотбар 6, drag&drop (упрощённо)
- Крафт (верстаки I–III, очередь)

### Этап 3 — Строительство
- Строительный план + молоток
- Фундамент / стены / двери
- Тиры: Twig → Timber → Stone → Plate
- Ядро базы (Base Core) + привилегия
- Базовая стабильность

### Этап 4 — Бой
- Несколько оружий с отдачей и разбросом
- ADS + гироскоп работают вместе
- Броня по таблице
- Лечение, «ранен»

### Этап 5 — PvE
- Животные с простым ИИ
- Бочки и ящики
- Аэродроп (событие)

### Этап 6–8 — Упрощённо
- Взрывчатка и разрушение построек
- Простые турели
- Боты-заглушки
- Торговля NPC

### Этап 9–10
- Настройки графики / FPS / FOV
- Capacitor + GitHub Actions для APK

## Управление

**Мобильный (landscape)**: левый стик, свайп камеры, кнопки огня/ADS/прыжок/инвентарь + **гироскоп**.

**ПК**: WASD + мышь, ЛКМ, R, E, Tab, 1–6.

## Технологии

- Three.js r128 (CDN, без бандлеров)
- Всё процедурное (текстуры, модели, звуки)
- Один объект `DATA` со всеми числами
- localStorage + версия сохранения

## Важно

Это **прототип**. Многие системы сильно упрощены для того, чтобы всё запускалось и было играбельно. Полный паритет с оригинальным промптом потребовал бы месяцев разработки.
